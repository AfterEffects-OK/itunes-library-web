外部サーバー連携 & 同期設定

リモートXML/JSONの取得（Pull）とAPIへの送信（Push）

1. サーバーからデータ取得 (Fetch / Sync)

2. サーバーへライブラリを送信 (Push / Upload)

ローカルで読み込んだ Library.xml の解析済みJSONデータを、独自APIや Google Apps Script (GAS) のWebアプリURLへPOST送信してクラウドを更新できます。

サーバー構築・ホスティングのヒント（GitHub Pages / NAS / GAS）
  • GitHub Pages / 静的Webサーバー: 本アプリの「JSON出力」ボタンで書き出した library.json をサーバーに配置し、そのURLを上の「リモートライブラリ URL」に設定するとスマホや他PCからも高速に同期できます。
  • Synology / QNAP NAS: Web Station等で Library.xml を公開フォルダに配置すれば、そのまま直接XMLのURLを指定して同期可能です（※CORS許可ヘッダーが必要な場合があります）。
  • Google Apps Script (GAS): doGet(e) でJSONを返し、doPost(e) でGoogleドライブ上のJSONファイルを上書き保存するスクリプトを組むと、完全無料のクラウド同期サーバーになります。
